# Changelog

<a id="en"></a>
## English

### 2026-11-25

- Shared persistence for D1, SQLite and PostgreSQL. The installer chooses the engine and retains the existing basic lists. Bound SQL, isolated local storage and optional trusted proxies are documented in the engine guide.

### 2026-11-24

Versioned authorization snapshots, focused OTP reads and stable lists when switching tabs or windows.

### 2026-11-09

Core authentication and administration template: email OTP, optional Google OAuth, MFA, recovery, trusted devices, permissions, basic lists, audit and registration. English setup supports ten configurable interface languages and local, Cloudflare or Resend email. Includes MIT licensing, branding notices and public technical guides.

This branch contains the reusable core. Advanced table engines and XLSX exports are excluded; see [template scope](docs/en/template-scope.md).

## हिन्दी

### 2026-11-25

- D1, SQLite और PostgreSQL के लिए साझा डेटा परत। इंस्टॉलर इंजन चुनता है और बुनियादी सूचियाँ रखता है। गाइड में पैरामीटर वाला SQL, अलग स्टोरेज और वैकल्पिक विश्वसनीय प्रॉक्सी हैं।

### 2026-11-24

संस्करणयुक्त प्राधिकरण स्नैपशॉट, बेहतर OTP क्वेरी और टैब या विंडो बदलने पर स्थिर सूचियाँ।

### 2026-11-09

प्रमाणीकरण और प्रशासन टेम्पलेट: ईमेल OTP, वैकल्पिक Google OAuth, MFA, पुनर्प्राप्ति, विश्वसनीय डिवाइस, अनुमतियाँ, सामान्य सूचियाँ, ऑडिट और पंजीकरण। अंग्रेज़ी सेटअप में दस भाषाएँ और local, Cloudflare या Resend ईमेल चुने जा सकते हैं। MIT लाइसेंस, ट्रेडमार्क सूचनाएँ और सार्वजनिक तकनीकी मार्गदर्शिकाएँ शामिल हैं।

इस शाखा में पुन: उपयोग योग्य मुख्य प्रणाली है। उन्नत टेबल इंजन और XLSX निर्यात शामिल नहीं हैं; [टेम्पलेट का दायरा](docs/hi/template-scope.md) देखें।
