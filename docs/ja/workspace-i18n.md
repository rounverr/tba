> [!TIP]
> コードと setup アシスタントは英語を基準とします。10言語の翻訳とローカルフォントを同梱しています。`npm run setup -- --languages en,pt` は英語とポルトガル語のみを有効化し、追加パッケージのインストールや他の翻訳の削除は行いません。`--languages` を省略すると現在の選択を維持し、一覧がない設定では全10言語が有効です。英語は翻訳フォールバックとして常に有効です。`--locale en` で既定言語を指定でき、有効な言語を選べます。保存設定、対応ブラウザー言語、設定した既定値の順に解決します。言語変更でページやフォームは再読み込みせず、アラビア語の RTL も保持します。

ログイン、公開ページ、管理、ダイアログ、検証、メールは `en`、`es`、`pt`、`de`、`fr`、`it`、`zh`、`ja`、`hi`、`ar` に対応します。優先順位は有効な保存設定（`tba-language`）、`navigator.languages`/`navigator.language` の最初の対応言語、英語です。`es-AR`、`pt-BR`、`en-GB` などを正規化します。

セレクターは、言語のシンボルと矢印を持つ48×38pxのボタンです。メニューには、10つのネイティブ名、短いコード、および現在の選択肢が表示され、テーマの色とサーフェスが使用されます。幅と高さは、利用可能なスペースに制限されます。`ui/select.tsx` が再利用され、シリアル化のためにネイティブのセレクトボックスが隠され、トリガーコンテンツ、ヘッダー、およびオプションの寸法が追加されます。その他のセレクトボックスは、値と動作を保持します。

メニューは、矢印、ホーム/エンド、初期文字の入力、エンター、エスケープ、タブ、および外部のクローズをサポートします。選択またはエスケープでキャンセルすると、フォーカスはコントロールに戻ります。言語のグリフは安定しており、矢印のみが回転します。減少した動き、キーボード、スクリーンリーダー、モバイル、およびRTLが尊重されます。セレクターは、ログインとアプリのヘッダーにのみ表示されます。ダイアログとフォームは、この設定を継承し、独自の言語コントロールを含みません。

## テキストとデータ

`AuthI18n` は、パネルのコンテキストを再利用します。`page=panel` は、言語と方向を設定しますが、管理はビューごとのタイトルと既存の認証ガードを保持します。パネルの初期出力は、認証されるまで空のままです。

`src/lib/i18n/panel/*.json` は、パネルのカタログを中央化します。`panel.ts` は、フォールバックとパラメーターを適用します。`panel-sources.json` は、既存のカノニカルラベルとサーバーのパブリックメッセージを、翻訳可能なキーで結び付けます。`use-panel.ts` は、コンポーネントにフォーマットを提供します。確認とダウンロードのダイナミックテキストは、キーとパラメーターを保持するため、開いている間に言語を変更できます。

`src/lib/i18n/config.ts` が言語と方向、`messages/*.json` と `panel/*.json` が辞書、`catalog.ts`、`panel.ts` と共有コンテキストがキー・引数・フォールバックを管理します。10辞書を完全に保ってください。不明なエラーは翻訳済みの公開文にします。名前、アドレス、独自ロール名、コードは翻訳しません。

`X-Auth-Language` は有効なメール言語を選び、権限には使いません。有効なヘッダーや受信者設定がなければアプリ既定値（初期は英語）を使用し、無効化された保存言語も既定値に戻します。未翻訳キーは英語へ戻ります。確認済みログイン・登録とパネル選択が既存 `verification` メタデータ（`mail-language:<userId>`）へ設定を保存し、遅延通知は受信者の言語を使います。変更でコードを再送せず、有効期限・試行回数・検証も変えません。旧エラー文も互換性のため認識します。

言語選択はログインとアプリのヘッダーにあり、ダイアログは設定を継承します。React は再読み込みや遷移なしに翻訳し、フォーム、セッション、現在の画面を保持します。パネルでの変更は将来のメール用に `POST /api/private/profile/language` も送信しますが、管理データを再取得しません。保存が禁止されていても現在の訪問中は翻訳できます。

## RTLとフォント

アラビア語は、サイドバーとパネルの余白を右に配置し、ウェルカム画像、矢印、コントロール、テーブル、およびダイアログを適応させます。メール、キー、およびコードは、LTRを保持します。長いボタンとセキュリティの行は、小さい画面に調整されます。メニューは、10つの言語のローカルフォントを使用します。CJKのサブセットには、パネルの新しいカタログの文字も含まれており、`scripts/build-auth-fonts.py` を介して組み込まれています。

## ファイルと検証

言語テストでは、Better AuthとD1ローカルまたはシミュレートされたAPIを使用します。[マルチリンガルアクセスの実装](auth-i18n.md) を参照してください。

英語はフォールバックとして初期バンドルに含まれます。他のログイン・管理画面カタログは動的インポートとモジュール別メモリーキャッシュを使います。キーボードやポインターのフォーカスで該当オプションのみ先読みし、メニューを開くだけでは全言語を読み込みません。カタログが揃ってから切り替え、フォーム・セッション・画面遷移状態を保持します。キャッシュ済みの変更は通信不要で最後の選択が優先されます。初回失敗は英語、切り替え失敗は現在の言語を表示します。メールとビルド用メタデータは完全なサーバー専用辞書を使います。[言語読み込み](language-loading.md)を参照してください。
